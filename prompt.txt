Pe lângă reproducerea 1:1 a designului și conținutului website-ului de referință, tratează acest proiect ca pe un website public, production-grade, care va fi accesibil oricui pe internet.

OBIECTIV:

Website-ul trebuie să fie:

* extrem de profesionist
* rapid
* responsive
* accesibil
* sigur
* SEO-ready
* performant
* robust
* ușor de întreținut
* fără erori
* fără layout shifts
* fără comportamente nefinisate
* pregătit pentru deployment public.

IMPORTANT:

Nu modifica identitatea vizuală și nu face redesign.

Toate cerințele de mai jos trebuie implementate astfel încât să păstreze designul existent 1:1.

3. MOBILE FIRST QUALITY
=======================

* nu trebuie să existe horizontal scroll;
* footer-ul trebuie să fie perfect aranjat.

Nu micșora pur și simplu versiunea desktop.

Construiește o adaptare atentă a aceluiași design.

==================================================
4. ACCESSIBILITY
================

Respectă WCAG 2.2 AA cât mai mult posibil fără să modifici designul.

Implement:

* semantic HTML5
* header
* nav
* main
* section
* article unde este cazul
* footer
* proper heading hierarchy
* accessible buttons
* accessible links
* keyboard navigation
* visible focus states
* aria-label unde este necesar
* alt text pentru toate imaginile
* decorative images marcate corespunzător
* sufficient contrast
* reduced motion support.

Verifică:

prefers-reduced-motion

Dacă utilizatorul a dezactivat animațiile, redu sau elimină animațiile non-esențiale.

Nu folosi elemente clickable construite din div-uri dacă un button sau anchor este semantic corect.

==================================================
5. IMAGINI
==========

Imaginile sunt foarte importante pentru acest website.

Optimizează-le pentru web fără să compromiți aspectul vizual.

Folosește, unde este posibil:

WebP / AVIF

și fallback dacă este necesar.

Implement:

* width
* height
* aspect-ratio

pentru a preveni Cumulative Layout Shift.

Folosește loading="lazy" pentru imaginile below-the-fold.

Hero image:

NU o lazy-load-ui dacă acest lucru afectează LCP.

Folosește fetchpriority="high" pentru imaginea principală dacă este relevant.

Imaginile trebuie să aibă:

* alt text
* dimensiuni determinate
* crop stabil
* object-position corect.

Nu încărca imagini gigantice dacă sunt afișate la dimensiuni mici.

==================================================
6. PERFORMANCE
==============

Țintește:

LCP < 2.5s
INP < 200ms
CLS < 0.1

Optimizează:

* JavaScript
* CSS
* fonts
* images
* bundle size
* unnecessary dependencies
* render blocking resources.

Nu introduce biblioteci pentru lucruri care pot fi făcute simplu în CSS.

Evita JavaScript pentru layout atunci când CSS poate face același lucru.

Elimină dependencies nefolosite.

Nu încărca librării globale inutile.

==================================================
7. FONT LOADING
===============

Fonturile trebuie încărcate profesional.

Evită:

FOIT
FOUT excesiv
layout shift.

Folosește font-display corespunzător.

Dacă fontul este local:

preload doar pentru fonturile realmente critice.

Nu încărca 10 greutăți de font dacă sunt folosite doar 2.

==================================================
18. SECURITY
============

Chiar dacă este un frontend static:

* nu expune secrets;
* nu include API keys private;
* nu include tokens;
* nu include credentials;
* nu include .env secrets în repository;
* nu introduce inline scripts inutil;
* sanitizează orice input;
* evită dangerouslySetInnerHTML dacă nu este absolut necesar.

Verifică dependencies pentru vulnerabilități.

Rulează auditul package managerului disponibil.

Nu instala dependency-uri inutile.

==================================================
19. HTTP / SECURITY HEADERS
===========================

Dacă hosting provider-ul permite:

Content-Security-Policy
X-Content-Type-Options
Referrer-Policy
Permissions-Policy
Strict-Transport-Security

fără să blochezi accidental funcționalitatea website-ului.

CSP trebuie să fie realistă pentru aplicația finală.

Nu introduce o CSP copiată orbește care rupe fonturile, imaginile sau analytics.
